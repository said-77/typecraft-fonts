# TypeCraft Inspo — Curated Aesthetic & Canva Fonts

Aesthetic font directory and curated typography collections for Canva creators, graphic designers, and social media enthusiasts.

## Live Website
👉 **[View Curated Fonts Vault](https://said-77.github.io/typecraft-fonts/)**

## Featured Collections
- **Whimsical & Calligraphy Bundle:** Flowing cursive scripts & romantic ligatures for invitations and branding.
- **Minimalist Editorial Fonts:** High-fashion, clean serifs inspired by Vogue and luxury publications.
- **Retro Groovy Canva Collection:** Playful 70s display fonts, bubbly curves, and vintage lettering.
- **Boho Handwritten Essentials:** Organic signatures and warm journal handwriting for everyday social posts.

## Tech Stack
- HTML5 / Vanilla JS
- Tailwind CSS (CDN)
- Google Fonts (Playfair Display, Plus Jakarta Sans, Dancing Script, Caveat)
- Zero build tools required / 100% static & fast
